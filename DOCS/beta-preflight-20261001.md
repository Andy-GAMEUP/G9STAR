## 발견한 문제와 수정

- 견적이 브라우저에만 저장되면서 접수 성공으로 표시되던 문제: 서버 저장 성공 후 접수번호 표시.
- 빈 요청사항 입력이 검증 오류를 일으키던 문제: 선택 입력으로 처리.
- API 기본값이 방문자의 localhost를 가리키던 문제: `/api`로 통일.
- 쿠폰 목록이 브라우저 저장값에 의존하던 문제: `/v1/me` 서버 조회 추가.
- 관리자 화면이 `/dev/token`에 임의 역할을 요청하던 문제: 운영자 자격 증명으로 로그인하고 서버 권한 검사.
- 관리자 쿠폰 패널의 변경값이 요청마다 초기화되던 문제: 관리자 상태도 함께 저장.
- 인증 만료 시 무한 재시도 가능성: 오류 안내 후 재로그인.
- CATEGORY_MAP/REVIEW_SEED 초기화 이전 사용: 상세 화면 초기화 순서 수정.
- 360/390px 상품 화면 가로 넘침: 그리드 축소·카테고리 폭 수정.
- 기존 다른 도메인을 가리키던 canonical·공유 주소·사이트맵: g9star.co.kr로 수정.

## 검증 결과

- 기존 백엔드 회귀검사: 68 통과 / PostgreSQL 실DB 검사 4개 미실행.
- Cloudflare + PostgreSQL 베타 검사: 6개 통과. 저장소 재연결·동시 저장·권한·메일 모의검사·R2·요청 제한·상태 확인.
- 최초 D1 구성에서 Workers 화면 접수→관리자 조회, 회원가입→쿠폰 등록→새로고침 확인. 이후 Neon 전환은 PostgreSQL 엔진(PGlite)에서 별도로 저장·권한 회귀검사. Neon 실계정 연결과 브라우저 통합 검증은 배포 후 확인 필요.
- Workers 빌드 dry-run 확인. Cloudflare 운영 배포는 수행하지 않음.

운영 Neon·R2 연결, Turnstile 키, 관리자 비밀번호, 메일 발신 인증과 Secrets, 실제 도메인·Gmail 수신 확인은 계정 연결 후 완료해야 한다. 배포 절차와 작은 베타용 스냅샷 저장 한계는 `cloudflare/README.md`를 참조한다.
