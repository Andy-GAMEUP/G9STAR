# B2B2C 매장가구·인테리어 플랫폼 웹사이트 개발계획서

## 1. 프로젝트 개요

### 프로젝트명
B2B2C 매장가구·인테리어 커머스 플랫폼

### 개발 목적
소상공인 및 자영업자를 대상으로 매장용 가구, 인테리어 소품, 렌탈 서비스, 인테리어 디자인 지원, 견적 의뢰 및 온라인 구매/배송을 통합 제공하는 B2B2C 전자상거래 플랫폼을 구축한다.

본 플랫폼은 독립 쇼핑몰로 운영되는 동시에, 제휴 사이트와 채널링 연동하여 제휴 사이트의 고객이 이탈하지 않고 동일한 브랜드 경험을 유지하면서 상품 탐색, 견적 요청, 구매 및 배송까지 완료할 수 있도록 설계한다.

### 핵심 방향
- 사진 중심의 매장 쇼케이스
- 높은 가독성의 미니멀 UI
- 실제 매장 공간에서 사용된 가구와 상품 연결
- 제휴사 헤더 네비게이션 유지
- B2B2C 채널링 구조
- 온라인 구매 및 배송 자동화

## 4. 홈 화면 구성

### 4.1 제휴사이트 헤더 영역

제휴사 채널링 환경에서는 제휴사의 기존 헤더와 네비게이션을 그대로 유지한다.

| 항목 | 내용 |
|---|---|
| 로고 | 제휴사이트 로고 |
| 상단 메뉴 | 제휴사이트 기존 메뉴 |
| 검색 | 제휴사이트 검색 |
| 회원 | 제휴사이트 로그인 |
| 장바구니 | 통합 또는 연동 |

플랫폼 자체 메뉴는 제휴 헤더 하단에 별도 서비스 네비게이션으로 제공한다.

- 서비스소개
- 매장 쇼케이스
- 렌탈서비스
- 견적의뢰

---

### 4.2 Hero 영역

대형 매장 인테리어 사진을 전체 폭으로 배치한다.

**메인 카피**

> 당신의 매장을 더 특별하게  
> 가구부터 인테리어까지 원스톱으로

CTA:
- 서비스 소개 보기
- 견적 의뢰

## 5. 매장 쇼케이스

본 서비스의 핵심 콘텐츠 영역이다.

### 구성

- 카페
- 음식점
- 미용실
- 네일샵

각 매장 카드에는 다음 정보를 제공한다.

- 대표 사진
- 업종
- 스타일
- 사용된 주요 가구 수

### 상세 페이지

```text
매장 전체 이미지
   ↓
공간별 이미지
   ↓
상품 핫스팟
   ↓
상품 상세
```

---

## 6. 공간 내 제품 핫스팟

실제 매장 사진 위에 번호 또는 아이콘을 표시한다.

예시:

| 번호 | 상품 |
|---|---|
| 1 | 원목 테이블 |
| 2 | 카페 의자 |
| 3 | 펜던트 조명 |
| 4 | 수납장 |
| 5 | 바 스툴 |
| 6 | 식물/소품 |

사용자가 번호를 클릭하면 우측 또는 하단에 상품 정보가 표시된다.

- 상품 이미지
- 상품명
- 가격
- 옵션
- 장바구니
- 상품 상세

## 11. B2B2C 채널링 구조

### 핵심 원칙

제휴 사이트에서 유입된 고객은 가능한 한 제휴 사이트의 브랜드 경험을 유지한다.

### URL 예시

```text
partner-a.com/interior
partner-b.com/store-furniture
```

또는

```text
platform.com/?partner=partner-a
```

### 유지 항목

- 제휴사 로고
- 제휴사 헤더
- 유입 경로
- 캠페인 코드
- 주문 출처

### 데이터 저장

| 데이터 | 목적 |
|---|---|
| Partner ID | 제휴사 구분 |
| Referral ID | 유입 추적 |
| Campaign ID | 캠페인 분석 |
| Order Source | 주문 정산 |

## 16. 기대 효과

- 제휴사의 기존 고객 트래픽을 활용한 B2B2C 매출 확대
- 사진 중심의 매장 쇼케이스를 통한 상품 구매 전환율 향상
- 단품 판매와 렌탈, 견적 서비스를 동시에 제공하여 고객 생애가치(LTV) 증대
- 제휴사별 유입 및 매출 성과를 명확히 측정하여 파트너 확대 가능
- 향후 인테리어 시공사, 창업 플랫폼, 프랜차이즈 본사와의 채널링 확장이 용이한 플랫폼 구조 확보
